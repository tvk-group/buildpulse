# UX Laws: 77573.mp4
- Fitts: large close buttons, good mobile reach.
- Hick: reduce nonessential alternatives; keep disclosure visible.
- Chunking: group forms and complex payments into meaningful stages.
- Doherty: prompt honest feedback for clicks. 400ms from video is guidance, not a guarantee.
- Proximity: nearby labels, helper and errors.
- Von Restorff: one visually highlighted main task, not manipulative financial promotion.
Check keyboard, screen readers, reduced-motion, slow networks, blocked popups, error recovery and real task completion times.
