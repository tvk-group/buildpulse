# Premium web experience

Use reference video 70743 for cinematic product storytelling: polished product hero, deliberate image transitions, clear typography, and restrained depth. Use 71379 for fintech landing pages: strong dark/light contrast, product mockups, staggered feature reveals, and clear calls to action. Use 71154 for optional glass-style OTP visuals: clear focus states, paste/autofill support, accessible labels, and success/error feedback. Preserve real authentication, verification, rate limits, and KYC enforcement. Video 70744 suggests AI assistant UI patterns but does not establish that any particular voice software should be installed.

Prefer Motion React for React frontends, but check dependency installation and lockfile first. Prefer transforms and opacity, 150–450ms durations, no distracting infinite loops. Respect reduced-motion and keyboard/screen reader interactions. Keep mobile navigation usable and prevent CLS. Do not copy third-party trademarks, product imagery, or proprietary UI assets. Add visual regression and build checks before production deployment.
