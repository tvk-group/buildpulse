# TVK Design System — Local Selector

Follow the canonical, reviewed skills in `tvk-group/tvk-docs/.agents/skills/`:

- `tvk-design-system/SKILL.md` — selector, accessibility and release requirements
- `tvk-skeuomorphism/SKILL.md` — material trust and physical control affordances
- `tvk-glassmorphism/SKILL.md` — bright readable layered UI
- `tvk-claymorphism/SKILL.md` — approachable human-centered surfaces
- `tvk-liquid-glass/SKILL.md` — restrained flagship highlights
- `tvk-spatial-ui/SKILL.md` — infrastructure topologies with accessible 2D fallback

Choose one primary visual system and at most one secondary accent. Keep the project's actual brand, approved logos, content, architecture, framework, RTL/localization, accessibility, keyboard/touch behavior, responsive sizing, performance, reduced-motion behavior and compliance boundaries.

Skill installation is not a live UI change or security test. Make and review actual component changes separately. Do not add dead controls, fabricated metrics, fake payment statuses, decorative-only forms or unsupported service claims.

Railway is the sole deployment platform; use the service's actual connected source branch for later runtime changes. The skills rollout branch must not be mistaken for an approved production release.
