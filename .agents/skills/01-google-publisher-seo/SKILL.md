# Google Search & Publisher SEO
Reference video: 77564.mp4.
- Validate canonical domains, indexed 200 pages, sitemap, robots, hreflang, accurate author and publisher identity, JSON-LD NewsArticle for editorial articles.
- Only publishers eligible for Google's source preference selector should render the official Google Preferred Sources interactive control.
- Preferred Sources is opt-in per reader; it is NOT a global ranking factor or guaranteed AI Overview placement.
- Official standard embed in editorial pages: `<script async src="https://news.google.com/swg/js/v1/publisher.js"></script>` and `<div google-add-preferred-source-btn></div>`.
- Check site eligibility and measure Search Console effects rather than asserting a ranking boost.
Reference: https://developers.google.com/search/docs/appearance/preferred-sources
